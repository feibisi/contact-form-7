这个联系表单插件的内置功能是有限的，但是，在各种外部服务的帮助下，您的联系表单的可能性是无限的。
您可以在 联系 > 集成 中管理与外部 API 的集成。列出了多个类别的服务。如果您对这些服务感兴趣，请访问他们的说明页面以了解更多信息。

- [Sendinblue 集成](https://contactform7.com/sendinblue-integration/)
- [Constant Contact 集成](https://contactform7.com/constant-contact-integration/)
- [Stripe 集成](https://contactform7.com/stripe-integration/)
- [reCAPTCHA (v3)](https://contactform7.com/recaptcha/)
