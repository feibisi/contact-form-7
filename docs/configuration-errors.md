Contact Form 7 提供了 Configuration Validator，它可以验证您的联系表单配置以检测错误；这使您免于日后配置错误可能带来的麻烦。本系列文章解释了常见错误以及如何解决这些错误。
配置验证器的一般信息和介绍在[关于配置验证器的常见问题解答中](https://contactform7.com/configuration-validator-faq/)进行了解释。

#### 表单选项卡中的错误

- [表单控件使用了不可用的名称。](https://contactform7.com/configuration-errors/unavailable-names/)
- [多个表单控件位于单个标签元素中。](https://contactform7.com/configuration-errors/multiple-controls-in-label/)
- [表单模板中使用了不可用的 HTML 元素。](https://contactform7.com/configuration-errors/unavailable-html-elements/)
- [点用于表单标签名称。](https://contactform7.com/configuration-errors/dots-in-names/)

#### 邮件选项卡中的错误

- [有一个可能的空字段。](https://contactform7.com/configuration-errors/maybe-empty/)
- [使用了无效的邮箱语法。](https://contactform7.com/configuration-errors/invalid-mailbox-syntax/)
- [发件人电子邮件地址不属于站点域。](https://contactform7.com/configuration-errors/email-not-in-site-domain/)
- [存在无效的邮件标题字段。](https://contactform7.com/configuration-errors/invalid-mail-header/)
- [附件文件不存在。](https://contactform7.com/configuration-errors/file-not-found/)
- [不允许使用 wp-content 目录之外的文件。](https://contactform7.com/configuration-errors/file-not-in-content-dir/)
- [附件文件的总大小太大。](https://contactform7.com/configuration-errors/attachments-overweight/)

#### 消息选项卡中的错误

- [HTML 标签用于消息中。](https://contactform7.com/configuration-errors/html-in-message/)

#### “附加设置”选项卡中的错误

- [使用过时的设置。](https://contactform7.com/configuration-errors/deprecated-settings/)
