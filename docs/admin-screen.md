#### 表格选项卡

![编辑器屏幕 2 的屏幕截图](/_images/editor-screen-2.webp)
 
表格编辑栏（❷）。您可以在此处使用 HTML 和[form-tags](https://contactform7.com/tag-syntax/#form_tag)自定义表单内容。此字段中的换行符和空行会自动使用  
和

HTML 标记进行格式化。
标签生成器 (❶)。通过使用这些标签生成器，您可以在不了解它们的情况下生成[表单标签](https://contactform7.com/tag-syntax/#form_tag)。
有关表单标签的更多信息，请参阅[编辑表单模板](https://contactform7.com/editing-form-template/)和[标签的工作原理](https://contactform7.com/tag-syntax/)。

#### 邮件标签

![编辑器屏幕 3 的屏幕截图](/_images/editor-screen-3.webp)
 
您可以编辑作为表单提交结果发送的邮件的邮件模板。您可以在这些字段中使用[邮件标签](https://contactform7.com/tag-syntax/#mail_tag)。
Mail(2)模板是一个附加的邮件模板，它可以具有与主邮件模板不同的内容，也可用。
有关更多信息，请参阅[设置邮件](https://contactform7.com/setting-up-mail/)。

#### 消息选项卡

![编辑器屏幕 4 的屏幕截图](/_images/editor-screen-4.webp)
 
您可以编辑用于各种情况的消息，包括“发生验证错误”、“请填写必填字段”等。
请注意，此处仅提供纯文本。不允许在消息字段中使用 HTML 标记和实体。
有关更多信息，请参阅[编辑消息](https://contactform7.com/editing-messages/)。

#### 附加设置选项卡

![编辑器屏幕截图 5](/_images/editor-screen-5.webp)
 
您可以在此处添加自定义代码片段。有关详细信息，请参阅[其他设置](https://contactform7.com/additional-settings/)。
